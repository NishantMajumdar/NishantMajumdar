### Hardware & Systems Engineering

#### AmbilightUI (C++ / WinUI 3)
A desktop-to-hardware synchronization suite for ambient lighting.
- **Protocol:** Uses the **Adalight Protocol** to stream pixel data to **Arduino Uno** via high-speed serial.
- **Hardware:** Integrated WS2812B LED strips with photoresistor-based auto-brightness and thermal monitoring via CA RGB.
- **Performance:** Optimized for < 15ms latency to maintain 60 FPS visual sync.

#### RealGaming (React Native / UDP)
A distributed motion-gaming platform that repurposes mobile sensors as PC controllers.
- **Networking:** Utilizes **UDP (User Datagram Protocol)** for zero-lag motion transmission.
- **Sensor Fusion:** Maps motion data from smartphone accelerometer to virtual OS-level key injections.
- **Input Emulation:** Implemented custom threshold detection for Tennis and Boxing; the system filters raw IMU data to trigger precise virtual key-presses based on swing velocity and G-force peaks.

#### Linux & OS Optimization
- **Environment:** Configured and daily-drive a high-performance triple-boot system (**Bazzite/Fedora/Windows**) using **rEFInd**.
- **Tuning:** Deep experience in kernel-level optimization, GPU performance profiles (LACT), and custom EFI skinning.
